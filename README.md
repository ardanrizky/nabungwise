# TabunganKu (NabungWise)

Aplikasi web pribadi untuk mencatat, menganalisis, dan memprediksi pencapaian target tabungan secara otomatis dan real-time.

🌐 **Demo Live:** [nabungwise.vercel.app](https://nabungwise.vercel.app)

---

## Fitur Utama

- **Dashboard Real-Time**: Pantau saldo terkini, progres target, sisa nominal, dan status jadwal tabungan (lebih cepat / tertinggal).
- **Forecasting Dinamis**: Estimasi tanggal target tercapai berdasarkan rencana rutin maupun laju tabungan aktual.
- **Kalender Interaktif**: Visualisasi jadwal menabung, detail transaksi per tanggal, dan pencapaian target mingguan.
- **Simulator Skenario**: Uji coba simulasi nominal, setoran tambahan, atau penarikan dana tanpa mengubah data asli.
- **Analytics & Arus Kas**: Grafik target vs realisasi kumulatif, perbandingan setoran vs penarikan bulanan, dan evaluasi keuangan.
- **Backup & Restore**: Simpan dan pulihkan data kapan saja menggunakan file JSON atau ekspor ke CSV.

---

## Cara Menggunakan

1. **Buka di Browser**: Cukup buka file `index.html` langsung di browser Anda, atau akses melalui link [nabungwise.vercel.app](https://nabungwise.vercel.app).
2. **Setup Awal**: Masukkan saldo awal, target tabungan, nominal rutin, dan tanggal mulai menabung.
3. **Catat Transaksi**: Tambahkan setoran atau penarikan secara berkala, seluruh analitik dan prediksi akan otomatis diperbarui.

---

## Teknologi

- **HTML5 & Vanilla CSS**: Tampilan bersih, minimalis, responsif di HP/laptop, serta mendukung Dark Mode dan Light Mode.
- **Vanilla JavaScript**: Ringan, cepat, tanpa framework atau library pihak ketiga (*zero-dependency*).
- **Penyimpanan Lokal**: Menggunakan `localStorage` browser sehingga data tetap tersimpan saat halaman ditutup atau di-refresh.
